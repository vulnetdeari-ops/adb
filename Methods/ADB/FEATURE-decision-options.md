# Feature: decision options

**Status:** REJECTED — chip labels rejected; the rule is A/B/C (+ decide for me)
**Date:** 2026-08-26 (updated 2026-09-01)

## Goal
Tappable or labeled options under agent messages for Decision Questions, so the owner can click instead of type.

## Current rule (authoritative)
**A/B/C or 1/2/3** — when AGENTS.md requires a Decision Question (two different products or scopes). The owner answers with a single letter or number. The last letter is always decide-for-me.

Source of truth: project `AGENTS.md` → Decision Questions. ADB `SKILL.md` (DEFINE) and the German reading copy follow it.

Earlier drafts used Perplexity-style label chips. That was tested and rejected: typing label text is more work than a single letter. Chips are not the rule.
